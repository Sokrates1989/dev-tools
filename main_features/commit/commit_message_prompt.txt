  - Never list individual filenames or long comma-separated file lists.
  - If there is no clear single area/feature that covers all changes, omit "Area or feature:" entirely and start directly with the description.
- "description": Concise summary of all staged changes in this commit (not just a subset)
- Keep the "|" separators and "[]" brackets exactly as shown
- Wrap the command in bash syntax highlighting with backticks
